# AXIOMA · presentación web

Abre `index.html` en el navegador (o la dirección de GitHub Pages). Teclas: ← → cambiar · N notas del orador · F pantalla completa.

- Las diapositivas están en `slides/`, una por archivo; el orden, en `deck.json`.
- Fotos, render 3D y video del prototipo, en `assets/`.
- Después de editar una diapositiva: `python3 build.py` para regenerar `index.html`.
- Fotos: Pexels (licencia libre). Render 3D: modelo propio hecho con three.js.

Página publicada: https://joakovrd-designer.github.io/axioma/
